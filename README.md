# Holly & Reed — wedding website

A plain static site (HTML + CSS + a little JavaScript). No build step: open `index.html` in a browser, or host the folder on GitHub Pages / Cloudflare Pages / Netlify.

- **Pages:** one `.html` file per page. Edit the text directly.
- **Navigation:** the menu is defined once in `js/site.js` (`PAGES` list).
- **Countdown date:** `WEDDING_DATE` in `js/site.js`.
- **Colours and fonts:** variables at the top of `css/style.css`.
- **Background:** `images/background.svg` is a placeholder — swap it for your own artwork.
